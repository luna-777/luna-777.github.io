Summer 2026

ts-repo-metrics

Code analysis tool, built with a team

A shared tool that parses repositories with Tree-sitter and reports code metrics through a CLI, batch runs, and a Next.js dashboard. I rewrote the Cursor log parsing and built authenticated, versioned uploads for each user.

What looked fine: batch runs finished without errors.

What was happening: a parser buffer limit was silently dropping functions, so 197 of them never made it into the results.

What I changed: fixed the limit, then added batch manifests, regression tests, and explicit failure reasons so an incomplete run can't pass as a complete one. I also wrote per-function checks against three independent tools, which reached 99.81% exact agreement on 4,631 functions.

ALS-Decode

Brain-signal decoding for assistive communication

EEGNet training and per-subject calibration pipelines for motor-imagery and P300 EEG datasets, the kinds of signals used in brain-computer interfaces for people with ALS.

What looked fine: calibrating the model to each person seemed to improve accuracy.

What was happening: the gain came from a silent mismatch of 17 EEG channels between datasets, not from personalization.

What I changed: added channel validation, pinned checkpoints, and regression tests, then reran every experiment across subjects, random seeds, and folds.

PyTorch, MNE, MOABB, Hydra
